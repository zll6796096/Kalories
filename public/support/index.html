カロスキャン サポート

日本のApp Storeで公開するカロスキャンの利用案内です。

日本語

カメラを使えない場合

  1. iOSの「設定」からKaloriesを開き、カメラを許可してください。
  2. アプリへ戻って、もう一度カメラ画面を開いてください。

食べ物が写っていないと表示された場合

料理全体が明るく写るように位置を調整し、再撮影してください。 写真の選択だけでは外部へ送信されず、「分析する」をタップした後に送信されます。

ネットワーク、タイムアウト、RATE_LIMITED

接続を確認し、少し時間を置いてから手動で再試行してください。 ただし、サーバーが画像を読み取る前に正確なAPP_CHECK_FAILEDを返した場合だけ、 Kaloriesは整合性トークンを更新し、同じリクエストを1回だけ再送信します。 それ以外のエラーでは自動再試行しません。何度も連続して送信しないでください。

利用範囲

カロスキャンは一般の利用者向けですが、子ども向けカテゴリのアプリではありません。 栄養結果は一食分の参考推定であり、正確な測定値、医療診断または医療助言ではありません。 治療計画や栄養指導を目的とせず、臨床用途には使用しないでください。 データの送信と保持については プライバシーポリシーをご確認ください。

重要：公開Issueには、個人的な食事写真、認証情報、 APIキー、秘密情報を添付しないでください。Issueは誰でも閲覧できます。

中文

  • 无法使用相机时，请在 iOS“设置”中允许 Kalories 访问相机。
  • 提示没有拍到食物时，请让整餐清晰入镜后重新拍摄。
  • 遇到网络错误、超时或 RATE_LIMITED 时，请稍后手动重试。仅当服务器在读取图片前返回准确的 APP_CHECK_FAILED 时，App 才会更新完整性令牌并自动重发同一相片请求一次；其他错误不会自动重试。
  • 本 App 面向一般用户，但不属于儿童专区；结果只是单餐估算，不是医疗诊断或建议。
  • 数据发送和保存说明请查看隐私政策。

重要：公开 Issue 中不要附上个人餐食照片、凭据、API 密钥或秘密信息；任何人都可能看到公开内容。

English

  • If the camera is unavailable, allow camera access for Kalories in iOS Settings.
  • If no food is detected, place the full meal in clear view and retake the photo.
  • For a network error, timeout, or RATE_LIMITED response, wait and retry manually. Only when the server returns the exact APP_CHECK_FAILED response before decoding the image does the app refresh its integrity token and resend the same request once; it does not automatically retry other errors.
  • The App Store version is for general users but is not in the Kids category. Results are single-meal estimates, not medical diagnosis or advice.
  • Read the privacy policy for transfer and retention details.

Important: A public issue is visible to everyone. Never attach personal meal photos, credentials, API keys, or secrets.
